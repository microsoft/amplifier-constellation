Where it fits

Registration and local-location helpers operate on caller-owned records. The caller validates folders and owns persistence, identity, access and selection.

Supporting component.

  • Calling application (Python API) uses Amplifier Platform Workspaces.
  • Amplifier Platform Workspaces contains Registration and listing.
  • Amplifier Platform Workspaces contains Local-location interpretation.

Requirements, map sources, and implementation details
  • This is an independent open-source package hosted by bkrabach, not a Microsoft component in the Constellation family index.
