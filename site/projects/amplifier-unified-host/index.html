Where it fits

A separately composable AHP host for clients, durable conversation state and independently installed ACP agents.

Outward roles: Conversation, Connection. Supports: Experience, Agent Instance, Tool.

  • Amplifier Unified Host contains Conversation state & admission.
  • Amplifier Unified Host contains ACP agent bridge.
  • Independent AHP clients uses Amplifier Unified Host.
  • ACP agent bridge uses Configured ACP agents.
  • Amplifier Unified Host uses Optional Session Catalog.

Requirements, map sources, and implementation details
  • AHP server and ACP client roles are protocol roles, not new ecosystem primitives.
  • This is an independently composable host; do not label it the default installed backend of current Amplifier Unified.
  • Catalog and capability packages are optional. A same-origin authenticated gateway owns TLS and user account management.
  • Does not embed a model runtime or own every agent implementation.
