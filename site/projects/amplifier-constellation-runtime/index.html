Where it fits

A reasoning and tool-execution engine that an Instance or direct ACP client can use.

Supporting component. Supports: Agent Instance, Tool.

  • Constellation Instance (optional) uses Constellation Runtime.
  • Direct ACP client uses Constellation Runtime.
  • Constellation Runtime contains Model and tool loop.
  • Constellation Runtime contains Saved execution sessions.
  • Model and tool loop uses Model providers and tools.
