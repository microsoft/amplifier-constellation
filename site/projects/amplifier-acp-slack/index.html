Slack Connector for Amplifier

Give an existing ACP agent a presence in Slack channels, threads and direct messages.

Download Slack ConnectorRepository and documentation →

Where it fits

Connects existing ACP agents to Slack-owned conversations and presentation.

Outward roles: Connection. Supports: Conversation, Experience.

  • Slack Connector for Amplifier contains Channel and thread routing.
  • Slack Connector for Amplifier contains Inbox, outbox and session bindings.
  • Slack Connector for Amplifier contains Connector setup and administration.
  • Slack Connector for Amplifier integrates Slack conversations and UI.
  • Slack Connector for Amplifier uses ACP agent endpoint.

Requirements, map sources, and implementation details
  • Slack owns conversation membership/source messages; the agent endpoint owns reasoning and execution sessions.
  • Constellation Instance is optional; no required host or central provisioning service.
  • This focused architecture source does not establish a separately advertised Tool implementation, so do not invent one.
