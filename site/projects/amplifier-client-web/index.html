Requirements, map sources, and implementation details
  • Connects by the current Unified HTTP/SSE/WebSocket interface, not the separate AHP client interface.
  • Unified selects an exact accepted public source revision through its repository-delivery workflow; source changes require explicit selection, paired qualification and Unified release.
  • Developer source is not a standalone consumer installer.
  • The Shell SDK is an independently authored browser extension helper, selected through the client input lock and Unified assembly. A map or source release does not update the bundled client or qualify a host pairing.
