Amplifier Platform Status

Publish and read bounded local status observations. An independent Python library with command-line readers.

Read the library guideRepository and documentation →

Where it fits

A publisher, reader and optional hook exchange versioned local JSON observations. Callers choose private storage and session identity; no network service is introduced.

Supporting component.

  • Calling application (Python API) uses Amplifier Platform Status.
  • Amplifier Platform Status contains Publisher.
  • Amplifier Platform Status contains Reader and schema.
  • Amplifier Platform Status contains CLI and optional hook.
