Amplifier Platform Operations

Record operation evidence and deliver bounded coordination updates. An independent Python library.

Read the library guideRepository and documentation →

Where it fits

An operation journal and coordination helpers retain identities, output and recovery evidence. The calling application owns admission, permissions, cancellation and execution.

Supporting component.

  • Calling application (Python API) uses Amplifier Platform Operations.
  • Amplifier Platform Operations contains Operation journal.
  • Amplifier Platform Operations contains Coordination delivery.
