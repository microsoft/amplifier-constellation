Requirements, map sources, and implementation details
  • Catalog supports discovery; it does not own the conversation, start work, delete history or prove a native lock is free.
  • No required global catalog service: hosts authorize results and configure allowed roots.
  • Depict a reusable component with consumers, not a fixed child of a particular web client.
