Where it fits

A reusable library for immutable site snapshots, local previews and reviewed publishing.

Supporting component. Supports: Tool, Experience.

  • Embedding application uses Amplifier Publishing.
  • Amplifier Publishing contains Static snapshot capture.
  • Amplifier Publishing contains Local preview listeners.
  • Amplifier Publishing contains Reviews and deployment records.
  • Amplifier Publishing uses Configured publishing target.

Requirements, map sources, and implementation details
  • The library supports tool/experience integration but is not itself a standalone Experience or model/runtime.
  • Capture accepts prebuilt files; it does not run builds.
  • It does not supply public URL provisioning, DNS, cloud accounts, remote authentication or TLS.
