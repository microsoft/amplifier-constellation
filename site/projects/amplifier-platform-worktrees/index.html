Amplifier Platform Worktrees

Inspect and manage Git worktrees with ownership and recovery receipts. An independent Python library.

Read the library guideRepository and documentation →

Where it fits

Bounded Git operations and durable receipts support explicit inspect, create, attach, status and remove requests. The caller chooses the operation and retains cleanup responsibility.

Supporting component.

  • Calling application (Python API) uses Amplifier Platform Worktrees.
  • Amplifier Platform Worktrees contains Bounded Git operations.
  • Amplifier Platform Worktrees contains Durable ownership and recovery receipts.
