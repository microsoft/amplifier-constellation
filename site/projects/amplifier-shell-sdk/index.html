Requirements, map sources, and implementation details
  • This is an independent open-source library hosted by bkrabach, not a Microsoft component in the Constellation family index. Its original extraction and repository history remain recorded in ORIGIN.json.
  • The package @amplifier/shell-sdk exposes browser component helpers for host API 1.0. It is not a terminal shell, agent runtime, network service or implementation of a complete Constellation role.
  • Component authors bundle the helper and accept React and state from the host. Unified retains manifest compatibility, capability discovery, validation, activation and authority; trusted same-origin extensions are not isolated by this library.
  • Public source ownership, a qualified release tarball, consumer input selection and app release are separate steps. This map does not change an installed default or establish host compatibility; npm registry publication is separate.
