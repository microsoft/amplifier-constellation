Requirements, map sources, and implementation details
  • Current app uses Core AmplifierSession through Foundation prepared bundles.
  • Do not depict amplifier-unified-host, amplifier-unified-client-web or AHP as already replacing current app architecture; the architecture packet explicitly keeps that adoption a secondary track.
  • amplifier-client-web is the sole authoring owner; Unified prepares an exact public repository revision and ships its verified built assets. Source merge is not automatic app delivery.
  • Role mapping describes responsibility, not a claim that every Constellation family contract has been qualified.
  • The independently authored Shell SDK supplies trusted browser extension helpers. Unified retains host contracts, validation and activation; source publication and explicit app input selection remain separate.
