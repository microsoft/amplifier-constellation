Where it fits

A kernel manager and child runners use caller-supplied process operations, observation and trusted runtime paths. The caller owns process authority and cleanup.

Supporting component.

  • Calling application (Python API) uses Amplifier Platform Kernels.
  • Amplifier Platform Kernels contains Kernel manager.
  • Amplifier Platform Kernels contains Python runner.
  • Amplifier Platform Kernels contains Node runner.
