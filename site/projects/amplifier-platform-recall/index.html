Where it fits

A SQLite search and note store plus personalization attempt receipts retain caller-supplied evidence. The caller supplies allowed sources and owns context assembly, models and Stop.

Supporting component.

  • Calling application (Python API) uses Amplifier Platform Recall.
  • Amplifier Platform Recall contains Search and versioned note store.
  • Amplifier Platform Recall contains Personalization attempt receipts.
