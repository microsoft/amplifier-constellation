Where it fits

An HTTP/SSE wrapper over Amplifier Core and Foundation with pluggable endpoint extensions.

Supporting component. Supports: Agent Instance, Connection, Tool.

  • Amplifier daemon contains HTTP routes & SSE transport.
  • Amplifier daemon contains SessionManager / EventBus.
  • Amplifier daemon contains Plugin discovery.
  • Amplifier daemon uses Amplifier Core.
