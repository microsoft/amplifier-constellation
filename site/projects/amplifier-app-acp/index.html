Supporting component. Supports: Agent Instance, Connection, Tool.

Requirements, map sources, and implementation details
  • Execution adapter is not the Constellation Instance installation manager and is not amplifier-agent.

  • Do not label ordinary ACP support as compliance with every Agent Instance lifecycle contract.
